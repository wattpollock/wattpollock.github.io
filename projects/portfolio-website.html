Personal Portfolio Website

I built this portfolio site from scratch with HTML and CSS to document my cybersecurity projects, then deployed it free with GitHub Pages. It uses no frameworks, so I wrote and understand every part of it.

Terminology

  • HTML: the markup that defines a web page's structure and content.
  • CSS: the styling language that controls colors, layout, and fonts.
  • Git: a version-control tool that tracks changes and pushes code to GitHub.
  • GitHub Pages: a free service that hosts a website straight from a GitHub repository.

The following steps detail how I built and deployed the site:

  1. Build the pages
    Hand-wrote the HTML for a home page, an about page, a projects page, and individual project write-ups, using semantic tags and a shared stylesheet.
  2. Style with CSS
    Created a single style.css with a dark theme, a navigation bar, content cards, and a consistent color palette used across every page.
  3. Organize the repository
    Structured the site into folders (pages/, projects/, img/) and used relative paths so every page links correctly.
  4. Deploy with Git and GitHub Pages
    I tracked the site with Git and pushed it to a GitHub repository named wattpollock.github.io. GitHub Pages automatically serves any repository with that name as a live website, so enabling Pages in the repository settings published the site at wattpollock.github.io. Every time I push a change with Git, the live site updates within about a minute.

Security note: External links use rel="noopener noreferrer" to prevent tabnabbing, and the site is a static page with no backend, which keeps the attack surface minimal. No secrets or credentials are stored in the public repository.
