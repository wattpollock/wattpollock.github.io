Proxmox VE Install on an HP Envy

I installed Proxmox VE on an HP Envy laptop to use as a home virtualization server. Running Proxmox lets me spin up multiple virtual machines on one piece of hardware, which I use for security labs and testing.

Terminology

  • Proxmox VE: a free, open-source platform for running virtual machines, managed through a web interface.
  • Hypervisor: the software layer that lets one physical machine run multiple virtual machines at once.
  • Host: the physical machine (the HP Envy) that runs Proxmox and hosts the VMs.
  • ISO: a single-file image of an operating system installer, flashed to a USB drive to boot from.

The following steps detail the Proxmox install:

  1. Download the Proxmox VE ISO
    Download the installer image from the official Proxmox downloads page.
  2. Flash the ISO to a USB drive
    Use a tool like Rufus or balenaEtcher to write the ISO to a USB flash drive, making it bootable.
  3. Boot the HP Envy from the USB drive
    Plug in the drive, restart the laptop, and open the boot menu (usually F9 or Esc on HP) to boot from USB instead of the internal drive.
  4. Run the installer
    Follow the Proxmox installer, choosing the target disk and setting a root password and management IP. This wipes the drive and installs Proxmox as the main operating system.
  5. Log in to the web interface
    After it reboots, reach the management interface from another device at https://<host-ip>:8006 and log in as root.
  6. Switch to the no-subscription repository
    A fresh install points at the paid enterprise repository, which blocks updates without a subscription. In the web UI, disable the enterprise repo and add the no-subscription repo so updates work. See the Proxmox package repositories guide for details.

Security note: Proxmox runs the management interface on port 8006. I keep this off the public internet and reach it only over my private Tailscale network, which reduces the attack surface of the server.
