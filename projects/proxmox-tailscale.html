Tailscale VPN on Proxmox

Tailscale creates a private mesh network so all connected devices behave as if they're on the same LAN. This lets me reach the Proxmox web interface and my VMs from anywhere, on any network, without exposing anything to the public internet.

Terminology

  • Host: the physical machine running Proxmox. VMs run on top of it, so the host is the landlord and the VMs are guests.
  • VM (Virtual Machine): a full computer running in software on the host, like my Kali Linux box.
  • IP address: a device's unique address on a network (for example 100.74.246.11).
  • 100.x.x.x: the x's are placeholders for your own numbers, which differ per device. Tailscale assigns every device an address starting with 100.
  • Mesh network: a network where every device connects directly to every other one, instead of routing through a central point.
  • Port (:8006): the number after the IP that picks which service to reach. Proxmox's web interface lives on port 8006.
  • Shell: the text command interface on the host, opened from Proxmox's "Shell" button.

The following steps detail the Tailscale setup:

  1. Install Tailscale on the Proxmox host
    Open the Proxmox shell (node → Shell) and run:
    curl -fsSL https://tailscale.com/install.sh | sh
  2. Start Tailscale and log in
    Run tailscale up. This prints a login link. Open it in a browser and sign in. The account used here owns the network, and the same account logs in on every future device.
  3. Find the host's Tailscale IP
    Run tailscale ip -4 to get the host's 100.x.x.x address.
  4. Install Tailscale on your other devices
    Install the Tailscale app on your laptop (or phone) and sign in with the same account to join the network.
  5. Access Proxmox remotely
    From any connected device, open https://100.x.x.x:8006 (your host's Tailscale IP). The Proxmox login loads from anywhere.
  6. Disable key expiry
    In the Tailscale Admin Console, click the ⋯ next to the host and choose "Disable key expiry" so the server doesn't drop off the network later.

Security note: Using Tailscale's private mesh means the Proxmox management interface is never exposed to the public internet. No port forwarding, no open ports. Access is limited to devices on my tailnet.
